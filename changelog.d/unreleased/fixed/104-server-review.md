- **The server sheds load across all its routes at once.** Its in-flight limit applied to each route separately, so the server as a whole could take far more than 64 requests at once; one limit now covers every route. A timed-out request answers 503 rather than 408, a subdirectory in `assets/` fails at load rather than 404ing, a non-UTF-8 `BLIT_ADDR` is refused rather than ignored, and the prerender counts `/cv/` and `/cv` as one page.
