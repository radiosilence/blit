- **Extraction reads a message as the template does.** A msgid is now the string its literal compiles to, so `\\`, `\t`, `\'`, `\u{…}` and the rest no longer produce an id the runtime never looks up. A `__`-family call whose English, context or plural is not a string literal fails extraction with its line, rather than being skipped or filed under the wrong key, and calls in `if` conditions, `match` subjects, loop iterators and macro defaults are found.
