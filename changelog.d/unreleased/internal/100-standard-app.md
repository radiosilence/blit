- **The site is a server-rendered app, prerendered for deployment.** The generator in `generator/` and `src/` is now `crates/blit`, laid out as the kōan standard lays out a web UI. `just serve` runs an axum server that renders each page on request; `just build` prerenders `dist/` by crawling that same server from each locale's root and writing every response, failing on a link that does not answer or a route no link reaches. Each page is a written-out `#[derive(Template)]` struct in place of the `page!` macro, so askama-analyzer analyses every page. The deployed site is byte-for-byte unchanged.
