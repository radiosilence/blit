- **The release build no longer uses LTO.** Fat LTO re-optimised the whole dependency graph, Typst included, on every build, and none of that work survives the cargo cache: a one-line change to the generator took about three minutes to rebuild locally and over five in CI. Without it the rebuild takes seconds. The binary runs once per build and finishes in about a second either way, so there was no runtime cost to pay back. `opt-level = 3` was already the release default.
